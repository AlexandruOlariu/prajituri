Un card viu, desenat în 3D

Cardul din dreapta este HTML real — interactiv și accesibil — dar randat în interiorul unui canvas cu noul API HTML-in-Canvas, ca să-l putem înclina și roti în spațiu. Mută mouse-ul peste el ca să-l vezi prinzând viață.

Pe browserele care nu au încă acest API experimental activat, cardul plutește elegant cu o animație CSS 3D — așa că totul funcționează oriunde.
